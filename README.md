# 👗 포리 & 준 도트 옷장 (Pori & Jun Pixel Wardrobe)

64×64 치비 도트 캐릭터 6명과 순수 도트 의상 50벌(ef01 ~ ef50)을 브라우저에서 바로 입혀보고, 모자 위치까지 1px 단위로 미세 조절해 PNG로 저장할 수 있는 인터랙티브 옷장입니다.

## ✨ 주요 기능
- **6 캐릭터 피팅**: 철중 · 지율 · 윤호 · 민 · 준 · 호뽀리 (characters/char01.png ~ char06.png)
- **50벌 의상 & 모자 믹스매치**: 세트 입히기 / 옷만 고르기 / 모자만 고르기 (clothes/ref01 ~ ef50)
- **모자 위치 1px 단위 조절**: 캔버스 마우스 드래그 · 십자 버튼 · 키보드 화살표(↑↓←→) · X/Y 슬라이더 · 캐릭터×모자별 위치 자동 저장
- **PNG 원클릭 내보내기**: 완성 캐릭터 64×64 / 의상+모자 전용 64×64 투명 PNG / 8배(512×512) 고화질 스냅샷

## 📁 폴더 구성
- index.html — 단일 파일 인터랙티브 도트 옷장 (GitHub Pages 메인 페이지)
- characters/ — 64×64 기본 캐릭터 스프라이트 6종
- clothes/ — 64×64 투명 의상 전용 스프라이트 50종 (ef01 ~ ef50)
